# 좋은 코드 리뷰 예시

## ✅ 구체적이고 실행 가능한 리뷰

**Good:**
```
파일: src/auth/login.ts:42
문제: 비밀번호를 평문으로 로깅하고 있습니다
코드: console.log('Login attempt:', { username, password })
제안: password를 로그에서 제거하거나 마스킹 처리하세요
수정 예시: console.log('Login attempt:', { username, password: '***' })
우선순위: High (보안 이슈)
```

**Bad:**
```
비밀번호 처리가 안전하지 않습니다.
```

## ✅ 컨텍스트를 고려한 리뷰

**Good:**
```
파일: src/api/users.ts:15-20
문제: 사용자 목록 조회 시 페이지네이션 없이 전체 데이터를 가져옵니다
영향: 사용자가 10,000명 이상일 때 성능 저하 및 메모리 부족 가능
제안: 페이지네이션 추가 (limit, offset 파라미터)
우선순위: High
```

**Bad:**
```
페이지네이션이 없네요.
```
