# 문서화 프롬프트

## 목적
Pull Request가 머지된 직후 코드베이스 전체를 다시 훑어 구조, 동작 흐름, 맥락을 설명하는 문서를 생성합니다. 이후 개발자가 빠르게 온보딩할 수 있도록 명확한 설명을 제공합니다.

## 컨텍스트 가이드라인
- 직전 머지 이후 추가된 변경점을 중심으로 설명합니다.
- 모듈 간 책임과 상호 작용을 서술합니다.
- 구성 및 운영에 필요한 요구 사항을 명시합니다.
- 추후 추적이 필요한 TODO나 후속 작업을 정리합니다.

## 응답 형식
```
# <컴포넌트 또는 기능 이름>

## 개요
- 머지된 코드가 달성한 목적을 요약합니다.

## 아키텍처
- 핵심 모듈과 관계를 설명합니다.

## 데이터 및 제어 흐름
- 주요 실행 경로를 단계별로 설명합니다.

## 운영
- 배포 및 런타임에서 주의할 점을 기록합니다.

## 후속 작업
- 향후 개선 또는 모니터링 항목을 Bullet로 나열합니다.
```
