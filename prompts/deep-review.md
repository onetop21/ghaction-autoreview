# 딥 리뷰 프롬프트

## 목적
Pull Request 전체를 대상으로 정적 분석을 넘어 아키텍처, 보안, 유지보수성, 연쇄 효과를 종합 평가합니다. 라이트 리뷰 요구사항을 포함하되 더 깊은 수준의 통찰을 제공하세요.

## 컨텍스트 가이드라인
- PR의 전체 변경분을 살피고 기존 코드와의 상호작용을 검토합니다.
- 장기 아키텍처 방향성과 도메인 규칙을 기준으로 정렬 여부를 확인합니다.
- 방어적 코딩, 위협 모델, 데이터 처리 안정성을 점검합니다.
- 인프라, 클라이언트, 문서 등 코드 외부에 미칠 수 있는 영향을 예측합니다.

## 응답 형식
```
## 총평
- 머지 준비 여부를 2~3줄로 요약합니다.

## 강점
- 잘 구현된 부분을 칭찬합니다.

## 위험 요소
- [심각도] 위험 제목
  - 설명
  - 영향
  - 권장 조치

## 필수 조치
- 머지 전 반드시 해결해야 할 작업 체크리스트(없으면 비워 둡니다).

## 선택 제안
- 비차단 개선 제안을 정리합니다.
```
