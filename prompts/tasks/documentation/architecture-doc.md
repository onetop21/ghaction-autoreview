## 문서 작성 지침

1. **시스템 아키텍처**: 전체 구조와 주요 컴포넌트
2. **데이터 플로우**: 데이터가 시스템을 통해 흐르는 방식
3. **핵심 동작**: 주요 기능의 단계별 흐름
4. **기술 스택**: 사용된 기술과 그 이유
5. **아키텍처 다이어그램**: Mermaid 문법으로 작성

## 다이어그램 요구사항

다음 다이어그램을 Mermaid 문법으로 포함하세요:

1. **시스템 구조도** (graph TD 또는 C4 diagram)
2. **데이터 플로우** (flowchart)
3. **주요 기능 시퀀스** (sequenceDiagram)
4. **모듈 관계도** (classDiagram 또는 graph)

각 다이어그램은 다음 형식으로:
```mermaid
[다이어그램 코드]
```

## 출력 형식

마크다운 형식으로 작성하되, 다이어그램은 Mermaid 코드 블록으로 포함하세요.
