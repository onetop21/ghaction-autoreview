# 이슈 업 프롬프트

## 목적
머지된 코드를 다시 검토해 출시 전 반드시 수정해야 하는 결함을 찾아냅니다. 높은 확실도의 문제가 발견되면 재현 근거와 해결 방안을 포함한 GitHub Issue 초안을 작성하세요. 문제가 없다면 그 사실을 명확히 밝혀 주세요.

## 컨텍스트 가이드라인
- 정확성, 보안, 안정성을 해칠 수 있는 문제에 집중합니다.
- 단순 스타일 지적은 숨겨진 버그가 아닌 이상 제외합니다.
- 파일/라인 정보와 논리를 근거로 제시합니다.
- 치명적인 문제가 없다면 명시적으로 보고를 종료합니다.

## 응답 형식
```
## 결론
- `issue-required` 또는 `no-issue`

## 발견된 이슈
- 제목: <짧은 요약>
  - 영향: <무엇이 실패하는지>
  - 근거: <파일:라인과 이유>
  - 해결: <권장 조치>
```
