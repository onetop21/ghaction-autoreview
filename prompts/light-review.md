# 라이트 리뷰 프롬프트

## 목적
최근 커밋을 기준으로 문법 오류, 정적 분석 경고, 기존 코드와의 컨벤션 차이, 메모리 누수 및 자원 관리 문제 가능성을 평가합니다. Pull Request 전에 작성자가 빠르게 수정할 수 있도록 간결한 리뷰를 작성하세요.

## 컨텍스트 가이드라인
- 머지를 지연시키거나 즉시 실패를 일으킬 가능성이 높은 문제를 우선 보고합니다.
- 저장소 전반의 관례와 어긋나는 패턴을 강조합니다.
- 자원 누수나 비정상적인 메모리 증가 가능성을 포착합니다.

## 응답 형식
```
## 요약
- 전반적인 상태를 짧게 설명합니다.

## 발견 사항
- [심각도] 제목
  - 원인
  - 위치
  - 해결 방안

## 다음 단계
- 작성자가 확인해야 할 선택 체크리스트.
```
